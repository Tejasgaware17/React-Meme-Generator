![React](https://img.shields.io/badge/React-18-blue?logo=react)

A simple and fun **Meme Generator** built with **React and Vite**.
This application fetches meme templates and allows users to generate custom memes by adding their own top and bottom text.

## Live Demo

🔗 https://tejasgaware17.github.io/React-Meme-Generator/

---

## Features

* Generate random meme templates
* Add custom **top text** and **bottom text**
* Dynamic meme image rendering
* Responsive UI
* Fast build using **Vite**
* Deployed using **GitHub Pages**

## Installation

Clone the repository:

```bash
git clone https://github.com/Tejasgaware17/React-Meme-Generator.git
```

Navigate to the project folder:

```bash
cd React-Meme-Generator
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

---

## Build for Production

```bash
npm run build
```

---

## Deployment

This project is deployed using **GitHub Pages**.

To deploy:

```bash
npm run deploy
```
